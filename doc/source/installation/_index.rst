Installation
===============


The latest state of the packages can be installed directly from the GitHub repository.

Installation using pip:
------------------------------

.. code-block:: shell
   :caption: pip install

   python3 -m pip install git+https://github.com/opentelekomcloud-community/otc-api-sign-sdk-python
  


Using requirements.txt
----------------------

To install add following to your requirements.txt:
  
.. code-block:: shell 
   :caption: requirements.txt

   git+https://github.com/opentelekomcloud-community/otc-api-sign-sdk-python
